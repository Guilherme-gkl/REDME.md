#Sobre o Projeto
Este programa aplica duas camadas de segurança a uma palavra secreta:
1. Camada 1: Cifra de César com valor de `SHIFT` fixo.
2. Camada 2: Deslocamento dinâmico somado aos valores de uma sequência matemática escolhida pelo usuário (PA, PG, Fibonacci ou Números Primos).

O sistema também faz o tratamento de strings, exibe logs de processamento na tela e grava um registro persistente no arquivo `resultado_criptografia.txt`.
